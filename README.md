#### 📱 1. Mobile FinTech Suite (Sector Prestamistas)

> **Aplicación móvil nativa diseñada específicamente para el modelo de crédito "Gota a Gota" en Colombia.**

* **Stack:** `Flutter`, `Dart`, `SQLite`, `REST API`.
* **Ingeniería:** Utiliza **SQLite** como motor de base de datos local embebido, permitiendo a los cobradores registrar cuotas, gestionar exclusiones, aplicar recortes y mantener el control exacto de la cartera de forma fluida directamente desde el dispositivo, sincronizando posteriormente con el backend.

#### 🖥️ 2. Datronix — Back-Office Administrativo

> **Sistema integral de gestión para distribuidoras y comercializadoras.**

* **Stack Backend:** `Java 17`, `Spring Boot`, `Spring Data JPA`, `Spring Lombok`, `CockroachDB`.
* **Stack Frontend:** `HTML5`, `CSS3`, `Vanilla JavaScript`. *(Sin frameworks pesados, garantizando un rendimiento puro y directo en el navegador).*
* **Ingeniería:** Arquitectura basada en bloqueos transaccionales pesimistas (`PESSIMISTIC_WRITE`) para inventario concurrente, gestión de remisiones, roles de bodega y un dashboard financiero interactivo.
