## 👨‍💻 Perfil Profesional

Ingeniero de Software y Analista de Datos enfocado en la construcción de arquitecturas empresariales de alto rendimiento y ecosistemas de software integrales. Especializado en la creación de servicios backend transaccionales utilizando **Java y Spring Boot**, así como en la maquetación de interfaces ultraligeras con **HTML, CSS y Vanilla JS**. Poseo una fuerte orientación hacia la **analítica de datos a gran escala (Big Data)** y el diseño de redes neuronales artificiales mediante **Scikit-learn**, combinando eficiencia algorítmica con una profunda capacidad crítica y analítica para la toma de decisiones basada en datos.

      <h3 align="center">📱 JControl (Gota a Gota)</h3>
      <br>
      <p>Aplicación móvil nativa <em>offline-first</em> diseñada para la gestión financiera en campo, control de cartera y administración de prestamistas bajo alta movilidad temporal y geográfica.</p>
      <p><strong>Stack Core:</strong> Flutter 3, Dart 3, SQLite.</p>
      <ul>

        <li><strong>Lógica Financiera Compleja:</strong> Soporte para frecuencias dinámicas de cobro, pagos retroactivos, días de gracia, cuotas parciales y reglas de mora porcentuales o fijas.</li>
        <li><strong>Seguridad y Notificaciones:</strong> Protección de acceso local mediante PIN (hash bcrypt) y programación automatizada de alertas locales para cuotas próximas a vencer y gestión de mora.</li>
        <li><strong>Analítica Integrada:</strong> Generación de reportes de cartera en PDF (visor integrado) y exportación de tablas analíticas en formato CSV.</li>
      </ul>
    </td>
    <td width="50%" valign="top">
      <h3 align="center">⚙️ Datronix Back-Office</h3>
      <br>
      <p>Sistema ERP/Back-Office desplegado en la nube para comercializadoras, centralizando el control de inventario, facturación, remisiones, terceros y analítica de ventas.</p>
      <p><strong>Stack Core:</strong> Java, Spring Boot, CockroachDB, Vanilla JS, HTML/CSS.</p>
      <ul>
        <li><strong>Núcleo Transaccional:</strong> Operaciones atómicas en Spring Boot con bloqueos pesimistas en base de datos (<code>PESSIMISTIC_WRITE</code>) para garantizar exactitud de inventario bajo alta concurrencia.</li>
        <li><strong>Arquitectura Cloud:</strong> Despliegue en Render acoplado a CockroachDB distribuida, integrando automatización de correos transaccionales vía Resend API y protección anti-fuerza bruta.</li>
        <li><strong>Frontend Latencia Cero:</strong> Interfaz construida puramente en Vanilla JavaScript para un DOM ultraligero y respuesta inmediata, sin dependencia de frameworks pesados.</li>
        <li><strong>Flujos de Negocio Granulares:</strong> Interfaces independientes por rol (Admin, Operador, Bodega) con trazabilidad inmutable desde la venta hasta el despacho de remisiones.</li>
      </ul>
