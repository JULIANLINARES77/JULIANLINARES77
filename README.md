### 🚀 Sobre Mí

Desarrollador enfocado en la construcción de sistemas **Backend robustos y de alto rendimiento en Java con Spring Boot**, procesamiento dinámico de datos mediante **Python/Pandas** y aplicaciones móviles multiplataforma en **Flutter**. 

Mi enfoque técnico prioriza la eficiencia arquitectónica, aplicando patrones híbridos e intermedios (integración eficiente entre el servidor Java y vistas HTML para evitar el overhead innecesario de backends desacoplados cuando no se requieren) y la observabilidad continua.
